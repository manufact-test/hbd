# BdaySquirrel

BdaySquirrel is a private, local-first Android birthday reminder app with a friendly pixel-art identity.

## Product model

- All core functionality is available to every user; there is no separate Free vs Pro feature set.
- New production users receive the complete app for the first 365 days.
- After the first year, continued normal use requires a one-time purchase.
- No ads and no recurring subscription are planned.
- Birthday data remains local-first and is never deleted when access expires.

## Project structure

- `branding/` — brand system, design tokens, logo and mascot assets
- `app/` — Android application source code
- `PROGRESS.md` — current implementation status, QA focus and product roadmap

## Visual direction

**Pixel Carved Retrowave** — dark plum surfaces, coral-orange squirrel mascot, cream typography, mint and lavender accents, carved pixel geometry and restrained arcade-inspired motion.
