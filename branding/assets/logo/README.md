# BdaySquirrel Logo Assets

## Files

- `bdaysquirrel-primary-logo.svg` — editable vector pixel reconstruction using only SVG rectangles and the approved brand palette.
- `bdaysquirrel-primary-logo.png` — transparent raster export of the approved primary logo concept.

## Concept

The primary logo combines a friendly coral pixel squirrel, a large tail suggesting the letter **S**, an acorn and a birthday candle. The custom pixel wordmark uses cream for “Bday” and coral for “Squirrel”, tied together by a dark plum outline.

## Usage

- Keep the logo on simple, high-contrast backgrounds.
- Prefer Night Plum (`#171226`) or transparent placement over a dark neutral surface.
- Do not add soft shadows, gradients, outlines or effects outside the approved artwork.
- Do not stretch, rotate or redraw individual parts independently.
- For very small sizes, use a dedicated symbol-only variant rather than shrinking the full wordmark.

## Status

This is the approved version 1 concept and the starting point for the production logo family. Small-size icon geometry and monochrome variants will be created separately.
