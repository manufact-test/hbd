# BdaySquirrel Logo Assets

## Files

- `bdaysquirrel-primary-logo.svg` — editable primary logo built entirely from SVG vector shapes.
- `bdaysquirrel-squirrel-icon.svg` — standalone editable squirrel mascot icon built entirely from SVG vector shapes.

## Concept

The primary logo combines a friendly coral pixel squirrel, a large tail suggesting the letter **S**, an acorn and a birthday candle. The custom pixel wordmark uses cream and coral accents tied together by a dark plum outline.

## Usage

- SVG is the only maintained logo format in this repository.
- Keep the logo on simple, high-contrast backgrounds.
- Prefer Night Plum (`#171226`) or transparent placement over a dark neutral surface.
- Do not add soft shadows, gradients, outlines or effects outside the approved artwork.
- Do not stretch, rotate or redraw individual parts independently.
- For very small sizes, use the symbol-only SVG rather than shrinking the full wordmark.

## Status

This is the approved version 1 concept and the starting point for the production logo family. Future logo variants must also be stored as SVG only.
